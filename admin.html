অ্যাডমিন লগইন

Firebase Authentication-এ তৈরি অ্যাডমিন ইমেইল ও পাসওয়ার্ড দিয়ে লগইন করুন।

অ্যাডমিনের অনুমতি Firestore Security Rules দিয়ে নিয়ন্ত্রণ করা হয়। Firebase config গোপন পাসওয়ার্ড নয়; কখনো অ্যাডমিন পাসওয়ার্ড কোডে লিখবেন না।
CONTENT MANAGEMENT

অ্যাডমিন ড্যাশবোর্ড

গল্প তৈরি করুন, প্রকাশ করুন এবং প্রকাশিত গল্প পরিচালনা করুন।

✍️ নতুন গল্প প্রকাশ

সব তথ্য পূরণ করে প্রকাশ করুন।

দীর্ঘ গল্পে পাঠকের জন্য “আরও পড়ুন” অপশন স্বয়ংক্রিয়ভাবে আসবে।

📚 প্রকাশিত গল্প

০টি

🔑 পাসওয়ার্ড পরিবর্তন

Firebase Authentication থেকে পাসওয়ার্ড পরিবর্তন করতে “পাসওয়ার্ড ভুলে গেছেন” সুবিধা বা Firebase Console ব্যবহার করুন।

গল্প Firestore-এ সংরক্ষিত হয়, তাই প্রকাশিত গল্প ইন্টারনেট-যুক্ত যেকোনো ডিভাইসে দেখা যাবে। নিরাপত্তার জন্য firebase-config.js-এ শুধু Firebase web config রাখুন এবং Firestore Rules-এ আপনার অ্যাডমিন UID বসান।
